📷 Make it a system camera (no screen share)

A webpage can't install a driver, so to see CamLink inside Zoom / Meet / Chrome's camera dropdown, you need a virtual driver.

  1. EasiestInstall OBS Studio → it installs OBS Virtual Camera.
  2. In OBS: + → Window Capture (PipeWire) → pick the CamLink tab.
  3. Click Start Virtual Camera in OBS.
  4. In Zoom/Meet/ome.tv, choose OBS Virtual Camera.
