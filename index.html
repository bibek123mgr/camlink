Setting up…

📷 Make it a system camera (no screen share)

A webpage can't install a driver, so to see CamLink inside Zoom / Meet / Chrome's camera dropdown, you need a virtual driver. Pick one:

  1. EasiestInstall OBS Studio (free) → it installs OBS Virtual Camera.
  2. In OBS: + under Sources → Window Capture → pick this browser tab.
  3. Click Start Virtual Camera in OBS (bottom right).
  4. Now in Zoom/Meet/Chrome settings, choose OBS Virtual Camera.

Alternative: Use EpocCam, Iriun, or DroidCam.
